# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射；带互证状态（未核/通过/阻断） |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到、阻断窗禁写 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 + 窗键归属互证履历 |

## 窗键对齐互证（已实现）

全局唯一口径：**合计加窗键归属**（不保留「只核合计」的甲口径，避免正确性分叉）。

- 每条 `已入窗` 事件按其**事件时**与当前对齐规则重算窗键，须与落库窗键一致；
- 窗表点赞/送礼/笔数须等于窗内事件求和；
- 任一不符 → 互证失败，列出错挂明细，涉事窗置「阻断」。**失败闭**：关窗扫描不得把阻断窗标发射成功，入流不得再写入（事件记 `已阻断` 进旁路匣），修复后重算通过才解除；
- 互证与入流共用主链锁 + 整事务（`BEGIN IMMEDIATE`），并发交错失败闭、不半截；
- 只读接口 `GET /api/窗键互证`：`valid`、错挂列表、逐窗合计，不写库；落阻断/履历走 `POST /api/贯验`。

测试：`cd backend && python -m pytest tests/`（含「合计凑齐但窗键错挂：甲可过乙必败」「失败后关窗不得标成功」「互证中入流不扩大脏窗」三类夹具场景）。
